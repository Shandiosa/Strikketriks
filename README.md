# Strikketriks – installerbar PWA

Legg hele `app/`-mappa på en HTTPS-adresse (GitHub Pages, Netlify, egen server) og åpne den i Chrome på Android → menyen → **Legg til på startskjerm**. Da får du appikon, helskjerm og offline-bruk.

Filer: `index.html` (hele appen), `manifest.webmanifest`, `sw.js`, ikoner.
